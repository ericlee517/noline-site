## 新建 Noline 小说宇宙官网（Astro）
- 路径：`D:/wildtree/PJ/noline-universe`（独立于 flint-site 的第二个 Astro 项目）。
- 技术栈：Astro 5 + 纯 CSS（无 UI 库）。字体用 Google Fonts（Inter / Noto Sans SC / Playfair Display）。
- 配色：粉色调简约现代（--bg #fff7fa, --pink #ff7aa8, --pink-deep #c2185b），含毛玻璃导航、Hero 光晕、IntersectionObserver 轻量滚动入场。
- 结构：`Layout.astro`（nav+slot+script）、`pages/index.astro`（Hero / 世界观 / 角色 / 作品 / 页脚）、`styles/global.css`、`data/universe.ts`（集中维护文案）、`public/favicon.svg`。
- 内容均为占位文案，集中在 `src/data/universe.ts`，便于替换为真实世界观/角色/作品。

## 环境注意（重要）
- 用**系统 Node**（`C:\Program Files\nodejs`，v24）跑 `npm install` / `npm run build`，不可用托管版 Node。
  - 原因：托管 Node 二进制 `.../workbuddy/binaries/node/.../node.exe` 被沙箱锁住，esbuild 的 postinstall 用 `spawnSync` 调用它会报 `EBUSY`，导致安装失败且 `@esbuild/win32-x64` 缺失。
  - 用系统 Node 装好后，`astro build` 正常（esbuild 0.27.7 可用）。
- 已装好的 `node_modules` 不要 `rm -rf`（沙箱 safe-delete 批量删除 >50 项需确认，会卡住）。如需重装，直接 `npm install`（增量补齐）即可。
- npm 会提示 esbuild/sharp 的 install-scripts 未被 allowScripts 批准——不影响构建（二进制来自可选包，postinstall 仅校验）。
